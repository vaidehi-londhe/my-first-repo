📊 Statistical Project Overview This project helps teachers analyze student performance: - Check if students have a higher or lower GPA - Identify the **Top 10 students** - Generate a **heatmap correlation** of grades - Highlight **at-risk students** - Provide a **summary report** for quick insights
Purpose:
The simulation helps showcase how satellite-based systems can be applied to track vehicles, providing insights into navigation, monitoring, and performance analysis.
