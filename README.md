🚗 Car Tracking Simulation using GPS & GPMS

This project demonstrates a simulation where GPS and GPMS are used to track a moving car through satellite data.  

Features:
- Real-time tracking of car movement
- Integration of GPS and GPMS signals
- Visualization of the car’s path
- Satellite-based monitoring for accuracy
- Useful for educational purposes in data analysis and simulation

Purpose:
The simulation helps showcase how satellite-based systems can be applied to track vehicles, providing insights into navigation, monitoring, and performance analysis.
